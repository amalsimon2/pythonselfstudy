# To-Do List Manager
## Description
A simple command-line application to manage a personal to-do list. Users can add, view, and mark tasks as completed.
## How to Run
1. Ensure you have Python installed on your system.
2. Save the above code in a file named `todo_manager.py`.
3. Open a terminal or command prompt.
4. Navigate to the directory where you saved `todo_manager.py`.
5. Run the application using the following command:
   ```bash
   python todo_manager.py
   ```
## Features
- **Add Task:** Allows users to add new tasks with descriptions.
- **View Tasks:** Displays all tasks, marking them as 'Done' or 'Pending'.
- **Mark Task as Done:** Marks a specific task as completed.
- **Exit:** Exits the application.
## Usage Example
1. To add a task:
   - Choose option 1 from the menu and enter a description.
2. To view tasks:
   - Choose option 2 to see all tasks with their statuses.
3. To mark a task as done:
   - Choose option 3 and enter the number of the task you want to mark as done.
4. To exit:
   - Choose option 4 to end the application.
## Notes
- This project is designed for beginners, using Python's standard library only.
- It does not require any external libraries or API keys.
