# Temperature Converter
This is a simple Python program that converts temperatures between Celsius, Fahrenheit, and Kelvin.
## How to Run
1. Save the code in a file named `temperature_converter.py`.
2. Open a terminal or command prompt.
3. Navigate to the directory where the file is saved.
4. Run the program by typing `python temperature_converter.py` and pressing Enter.
## Features
- Converts temperatures between Celsius, Fahrenheit, and Kelvin.
- Provides an interactive menu for easy use.
- Handles user input errors gracefully.
